# GiFo-RFC-0115 (Version 1.0.1)

**Power-of-Attorney Credential Definition (PoA-Definition)**

New Request for Comments of Gimel Foundation (GiFo RFC) - Establishung the Power-of-Attorney Credential Definition (PoA-Definition)

Abstract of RFC: The Power-of-Attorney Credential Definition (PoA-Definition) enables a structured, standardized way of sharing machine-readable attributes and parameters, which are being leveraged for granting power of attorney along both the subscription as well as request-specific Extended Tokens of the GAuth protocol.
